PARTH D. JOSHI — PORTFOLIO WEBSITE
==================================

WHAT'S INSIDE
- index.html  The complete website. All photos and the book cover are
              already built into this one file, so it works on its own.
- assets/     The background-removed photos and the book cover as separate
              image files, in case you need them elsewhere.

TO VIEW
Double-click index.html to open it in any browser. It needs an internet
connection for the fonts and animation libraries.

TO PUT IT ONLINE (free options)
- Netlify Drop: go to app.netlify.com/drop and drag this folder onto the page.
- GitHub Pages: upload index.html to a repository and turn on Pages.
- Vercel or any normal web hosting: upload index.html as the home page.

BEFORE SHARING: SET THE REAL EMAIL
Open index.html in a text editor (Notepad or VS Code), search for
   hello@example.com
and replace it with Parth's real email address. Save the file.
